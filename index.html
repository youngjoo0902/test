프로젝트 세팅

  1. node 설치 - https://nodejs.org/ 에서 윈도우용 노드 다운받아 설치
    • 노드확인 : 터미널에 npm -v 쳐서, 노드 설치되었는지 확인
    • 안되면 환경변수 확인 : 시스템보호 > 고급 > 환경변수 > 시스템변수에 Path 항목 찾아서, 편집 누르고 node 경로 제대로 들어갔는지 확인. 안들어갔으면 수동으로 node 실제 경로 쳐넣기
  2. vite 설치 : 프로젝트 폴더로 이동한 후, npm create vite@latest 기본값으로 전부 엔터 엔터 치면 설치됨 (해당 프로젝트만 적용됨)
    • 바이트 설치 안되면? powershell 관리자 권한으로 열어서, Set-ExecutionPolicy RemoteSigned 입력하고, y 입력 (권한문제)
    • 서버실행 npm run dev 쳐서 로컬호스트 실행
    • 로컬호스트 실행안되면, cd 경로 맞는지 확인
  3. vite 빌드와 배포 : npm install gh-pages --save-dev 설치
    • package.json 파일에 "scripts" 객체에 아래 프로퍼티 추가.
      "deploy": "gh-pages -d dist"
    • npm run build 하면 dist 폴더가 생성됨
    • github 는 root를 바라보기 때문에, root 에 vite.config.js 와 package.json 파일이 있어야 한다.
    • vite.config.js 파일의 내용에 이걸 넣는다.
      import { defineConfig } from 'vite'
      export default defineConfig({
      base: '/test/'
      })
    • 커밋 푸시하고, npm run deploy 실행한다. github 에서 actions 탭 보면, 상태를 확인할 수 있다.
  4. git 설치 - https://git-scm.com/ 에서 윈도우용 깃 다운받아 설치
  5. vscode 확장프로그램에서 git graph 설치
  6. git 저장소 연결 : 터미널에 git remote add origin https://github.com/아이디/저장소명.git
    • git config --global user.name "본인깃아이디" 입력
    • git config --global user.email "본인깃이메일" 입력
    • 커밋, 푸시 테스트 해보기
  7. git 호스팅 방법
    • repository 들어가서 settings 탭 > Pages > Source 에서 Build and deployment 선택 > main 선택 / root 선택 > save
