프로젝트 세팅

  1. 노드설치 - https://nodejs.org/ 에서 윈도우용 노드 다운받아 설치
    • 노드확인 : 터미널에 npm -v 쳐서, 노드 설치되었는지 확인
    • 안되면 환경변수 확인 : 시스템보호 > 고급 > 환경변수 > 시스템변수에 Path 항목 찾아서, 편집 누르고 node 경로 제대로 들어갔는지 확인. 안들어갔으면 수동으로 node 실제 경로 쳐넣기
  2. 바이트설치 : npm create vite@latest 기본값으로 전부 엔터 엔터 치면 설치됨
    • 바이트설치안되면? powershell 관리자 권한으로 열어서, Set-ExecutionPolicy RemoteSigned 입력하고, y 입력 (권한문제)
    • 서버실행 npm run dev 쳐서 로컬호스트 실행
    • 로컬호스트 실행안되면, cd 경로 맞는지 확인
  3. 깃설치 - https://git-scm.com/ 에서 윈도우용 깃 다운받아 설치
  4. vscode 확장프로그램에서 git graph 설치
  5. 깃 저장소 연결 : 터미널에 git remote add origin https://github.com/아이디/저장소명.git
    • git config --global user.name "본인깃아이디" 입력
    • git config --global user.email "본인깃이메일" 입력
